# Swift 6.2.3

Released 2025-12-12 as `swift-6.2.3-RELEASE` (Xcode 26.2). 1 proposal implemented in this version; each needs Swift 6.2.3 or newer.

### SE-0487: Nonexhaustive enums

This proposal provides developers the capabilities to mark public enums in non-resilient Swift libraries as extensible. This makes Swift `enum`s vastly more useful in public API of such libraries.
